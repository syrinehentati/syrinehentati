## 🚀 Projects

### [Vibe](https://github.com/syrinehentati/Vibe) — AI Email Agent
An MCP server that reads your contact's writing style and generates emails that sound exactly like them — not like a robot.
- Detects tone from email history using Gemini AI
- Exposes a `generate_email` tool via MCP (Model Context Protocol)
- Deployable on Railway with SSE transport
- `Python` `FastMCP` `Gemini API` `Pydantic` `Railway`

### [IncidentIQ](https://github.com/syrinehentati/AI-powered-support-ticket-analyzer) — AI Incident Intelligence Platform
A multilingual incident analysis platform I built because I was doing this work manually every day at my job.
- RAG pipeline with Gemini embeddings + cosine similarity search
- Surfaces semantically similar past incidents to inform new resolutions
- Bulk analysis via JSON/Excel upload with real-time progress
- Gets smarter the more incidents you resolve
- `NestJS` `TypeScript` `PostgreSQL` `TypeORM` `React` `Gemini API`
